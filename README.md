# RYOKO_ORACLE — 月の案内人

「りょうこ」と「れん」を切り替えて楽しむ、無料の固定文リーディングWebアプリです。黒・深紫・ゴールドを基調とした単体HTML構成で、ビルド・依存パッケージ・登録は不要です。

## 起動

`index.html` をブラウザで開きます。JavaScriptを有効にしてください。CSS・JavaScript・カードのSVGはHTML内にあります。人物画像も表示するには `assets` を同じフォルダに置いてください。

ローカルHTMLを制限するブラウザでは、Python 3がある環境で次を実行できます。

```sh
cd /workspace/ryoko-oracle
python -m http.server 8765 --bind 127.0.0.1
```

同じ端末で `http://127.0.0.1:8765/` を開きます。終了は Ctrl+C。

ユーザーの公開許可に基づき、GitHub Pages用のmainへ反映しています。公開先： https://teamkitstudio-dev.github.io/ryoko-oracle/

## 占いの流れ

1. 「女性 · りょうこ」「男性 · れん」から占い師を選択。
2. 生年月日を入力すれば「今日の運勢を見る」で日替わり運勢を表示できます。じっくり占う場合は恋愛・仕事・金運・総合を選択。カード占いでは生年月日・星座とも任意です。
3. 今の状況を選択。その状況に合った具体的な相談を3つから選択します。たとえば片思いなら「自分から連絡する？ もう少し待つ？」など。
4. **1枚目：今のあなた**を選び、相談の入口を読みます。まだ最後の結果は表示しません。
5. 「やってみたいがためらう／まだ分からないことが多い／考え続けて疲れた」から今の気持ちを選択。
6. **2枚目：気持ちの奥**を選び、回答に応じた補足とカードの読み解きを表示。
7. テーマに合った進み方を3つから選択。恋愛なら「短い言葉で伝える／相手の言動を見る／自分を整える」、仕事なら「相談・提案／情報を集める／負担と休息」など。
8. **3枚目：次の一歩**を選択。3枚すべてと、途中で選んだ気持ち・進み方を合わせた最終の読み解きを表示します。

状況ごとの具体的な相談は4テーマ×3状況×3相談＝36種類。途中の気持ちは3つ、進み方は各テーマ3つです。各段階は月・星・鍵・薔薇・鏡のA/B/C/D/Eの5枚から1枚を選び、同じカードを続けて選んでも構いません。3枚のカードは役割が異なり、最終まとめにそれぞれ反映します。

各文章はあらかじめ用意した固定文で、選択に応じて組み合わせます。同じ選択なら同じ内容です。AIとの自由会話や、相手の内心・未来の断定は行いません。占い師による本文の違いはなく、切り替えても進行状況と本文を保持します。

最終まとめは「最初の問い」「1枚目」「2枚目と気持ち」「選べる道の両面」「選んだ進み方」「3枚目と行動」「持ち帰る問い」の7節。星座指定時は補足を加えます。

### 戻る・やり直す

- 「ひとつ前に戻る」「前の読み解きに戻る」で前段階へ戻り、回答を修正できます。前の回答を変更すると、それ以降のカード・進み方は選び直しになります。
- 「3枚をもう一度引く」は同じ相談で1枚目からやり直します。
- 「相談を選び直す」は状況・具体的な相談へ戻ります。同じテーマでは既存の選択を保持します。
- 状況を変更すると、質問が切り替わり以前の質問への回答を消去します。テーマを変更すると、状況と質問の回答を消去します。
- 「最初に戻る」はテーマ・星座へ戻ります。リロードではすべて初期化し、入力は保存されません。

| テーマ | 状況の選択肢 |
| --- | --- |
| 恋愛 | これからの出会い／気になる人・片思い／交際中・パートナーとの関係 |
| 仕事 | 今の職場・人間関係／転職・働き方の見直し／評価・成長・新しい挑戦 |
| 金運 | 日々の支出・家計／貯蓄・これからの安心／買い物・お金の使い方 |
| 総合 | 疲れ・心の余裕／人との距離・付き合い方／これからの方向・やりたいこと |

## 今日の運勢

生年月日を入れて「今日の運勢を見る」を押すと、総合メッセージ、恋愛・仕事・金運、ラッキーカラー、小さな行動を表示します。同じ生年月日と日本時間の日付なら、何度開いても同じ結果です。外部AIや天体情報APIを使わず、用意した文章を日付に応じて組み合わせます。文章は一定の周期で再利用されます。

日付は表示端末のタイムゾーンに関係なく日本時間（Asia/Tokyo）を使います。午前0時を過ぎた後、表示中は最大1分間隔の確認で更新し、バックグラウンドから戻ったときにも確認します。厳密な天体計算や未来の保証は行いません。星座だけを選んだ場合は日替わり運勢は表示せず、カード占いは続けられます。

誕生日の変更・消去、星座の手動変更時は古い日替わり結果を隠します。再表示には生年月日が必要です。生年月日は端末内のメモリと入力欄だけで扱い、送信・保存しません。リロード後は再入力します。

## 生年月日・星座とプライバシー

生年月日はブラウザ内で星座と日替わり運勢を求めるために使います。星座は一般的な日付区分で月日から求め、日替わり運勢は生年月日全体と日本時間の日付を文章選択の入力にします。年齢の推定はせず、未来の日付は受け付けません。

出生時刻・出生地・天体暦を使う精密なホロスコープ計算ではありません。星座の境界日は資料や年によって異なる場合があるため、フォームにその旨を表示し、星座を直接選べるようにしています。星座を手動変更すると、誕生日との不一致を避けるため生年月日欄を消去します。

アプリによる生年月日・選択内容の保存・送信はありません。Cookie・localStorage・アクセス解析・ログイン・外部AI API・外部ライブラリ・外部フォント・決済は使いません。フォームはJavaScriptで処理し、画面遷移のクエリやPOSTに入力値を含めません。

占いは娯楽・自己理解のためのコンテンツです。未来や第三者の気持ちを断定しません。金運の本文では収益を保証せず、占いによる投資・借入の決定を促しません。

## 画像とファイル

- `index.html`：画面、固定文、星座の日付区分、切り替え操作。
- `assets/ryoko.png`：ユーザー提供の元画像。画像データ・顔・衣装の加工はしていません。表示時にCSSで薄い深紫の陰影を重ね、男性画像との明るさをそろえています。
- `assets/ren.png`：このアプリ用に生成した架空の男性占い師「れん」（仮名）。
- `assets/card-moon.webp`・`card-star.webp`・`card-key.webp`・`card-rose.webp`・`card-mirror.webp`：生成した5枚のカードイラスト。WebP化した5枚の合計は約1.7MBです。
- `assets/qr.png`：公開URLにアクセスするQRコード。
- `assets/README.md`：画像の説明。

人物画像はスマホ幅236px・デスクトップ幅264px。`object-fit: contain` で全体を表示し、読み込み失敗時は月の代替表示へ切り替えます。

## 3枚の進行について実行した検証

Linuxの実ChromiumをPlaywrightから操作し、ローカルHTTP配信で375px・390px・1440px幅（高さ900px）を検証しました。

- 各幅で実際のクリック・入力による一連の操作を検証：テーマ・生年月日→状況→具体的な相談→1枚目→気持ち→2枚目→進み方→3枚目→最終まとめ。1・2枚目で最終終了ボタンが出ず、途中回答なしでは次へ進まないことを確認。
- 男女切り替えによる本文・進行の保持、前の段階への復帰と回答の保持、以前の回答変更時の後続選択リセット、状況やテーマ変更時の質問切り替えとリセット、星座補足、リロード、1枚目からの再実行を確認。
- 各幅でフォームsubmitとカードクリックのDOM操作による追加検証：36の相談、9通りの途中回答経路、27通りの3枚の順序（同じカードの繰り返しを含む）。各検証群で最終本文がそれぞれ異なり、3枚がすべてまとめに表示されることを確認。全分岐の直積を網羅したテストではありません。
- 36相談を代表経路で読んだ最終結果は、3枚の表示・見出し込み1147〜1209字（星座補足なし）。
- 横スクロール・JavaScript例外は検出なし。操作中の通信はローカル画面・画像のGETのみで、クエリ・POST・外部宛先なし。
- 375px幅の1枚目・2枚目の読み解きと選択欄をスクリーンショットで目視確認。

前版で12星座の開始日前日・当日、うるう日、年末年始、未来の日付の拒否、星座の手動選択、画像失敗時の代替表示を検証しています。今回の日付ロジック・画像失敗処理の変更はありません。

未検証：iPhone Safari・Android実機、Chromium以外のブラウザ、`file://` 直接実行、公開URL上の本文と操作。直接実行・公開URLへのアクセスは実行環境の制限があります。公開処理はGitHub Actionsの対象コミットと成功状態で別途確認します。

検証範囲に未解決の操作不具合はありません。画像の利用権・本人の許諾は公開者が確認してください。自動の需要計測機能は搭載していません。

## 5択カードと日替わり運勢の最新検証
