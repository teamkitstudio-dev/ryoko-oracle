# RYOKO_ORACLE — 月の案内人 りょうこ

無料3択占いの需要検証用Webアプリです。黒・深紫・ゴールドを基調に、月・星・鍵のカードから固定メッセージを表示します。外部API、外部ライブラリ、外部フォント、ログイン、個人情報収集、決済、アクセス解析は使用しません。

## 開き方

`index.html` をブラウザで開いてください。ビルド・インストール・登録は不要です。JavaScriptを有効にしてください。CSS・JavaScript・カードのSVGはHTML内に含まれています。

端末やブラウザがローカルHTMLを制限する場合は、Python 3がある環境で次を実行できます。

```sh
cd /workspace/ryoko-oracle
python -m http.server 8765 --bind 127.0.0.1
```

同じ端末のブラウザで `http://127.0.0.1:8765/index.html` を開きます。終了は Ctrl+C。外部公開用の手順ではありません。

## ファイル

- `index.html`：画面、スタイル、3種類の固定リーディング、カード選択と戻る操作。
- `assets/README.md`：りょうこの元画像の配置方法。
- `assets/ryoko.png`：元画像提供後に配置するファイル。現時点では含まれていません。

画像未設定・読み込み失敗時は月の代替表示になります。画像が正常に読めたときだけ元画像に切り替えます。`object-fit: contain` により画像を切り抜きません。別人の顔画像は作成していません。画像未設定時の `assets/ryoko.png` の404／ファイル未検出は想定内で、破損画像アイコンは表示しません。

## 操作と内容

- A＝月、B＝星、C＝鍵。メッセージはそれぞれ136字・145字・144字です。
- 「もう一度占う」でカード選択に戻り、別のカードを選べます。同じカードは同じ固定文になります。
- 「最初に戻る」でカード選択に戻り、ページ先頭へ移動します。
- リロードすると初期画面になります。選択結果は保存しません。
- 娯楽・自己理解のための占いであり、未来や第三者の気持ちを確定しない旨を画面に記載しています。

## 実行した検証

Linuxの実ChromiumをPlaywrightで操作し、ローカルHTTP配信で実行しました。外部への公開はしていません。

| 項目 | 結果 |
| --- | --- |
| 375px・390px・1440px幅（高さ900px）のカード選択画面・結果画面 | スクリーンショットと表示確認を実施 |
| 各幅でカードA/B/Cを選択 | 対応する異なる本文を表示、100〜180字内 |
| 各カードから「もう一度占う」 | カード選択へ戻る |
| 「最初に戻る」 | カード選択・ページ先頭へ戻る |
| 結果表示後のリロード | 初期画面へ戻る |
| 画像未設定 | 月の代替表示、破損画像表示なし |
| 横スクロール | 初期画面・各カード結果で発生なし |
| JavaScript例外 | 検出なし |
| キーボードのTab・Enterによる選択 | 操作成功 |

未検証：iPhone Safari・Android実機、Chromium以外のブラウザ、提供予定の元画像での表示、`file://` での直接実行。検証環境のChromiumは管理ポリシーにより `file://` を拒否したため、直接実行の結果は確認できていません。HTML自体にはサーバーや通信APIを必要とする処理はありません。
