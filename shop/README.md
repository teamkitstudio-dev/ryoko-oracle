# 恋愛リーディングブックの商品案内

- `index.html`・`style.css`・`shop.js`：販売案内と無料サンプルへの導線。
- `sample.pdf`：無料サンプル4ページ。
- `sample.html`：スマホ対応のブラウザ用サンプル。PDFと同じDAY1を収録。
- `assets/cover.webp`：本編の実際の表紙画像。
- `config.json`：980円・本編20ページ・サンプル4ページ、販売先と購入URLの設定。

本編PDF・本文の生成ソースは公開リポジトリの外で別管理しています。このディレクトリには無料サンプルのみを置きます。

初期状態は `saleEnabled: false`、`checkoutUrl: null`。購入ボタンは表示せず「販売準備中」とします。サンプルは読めます。実際のBOOTH商品を登録し、ショップ所有者から商品URLが届いた後にだけ、購入URLと販売状態を変更します。

購入先は `https://aimodelgallery.booth.pm/items/数字` に限定し、不正なURL・設定の取得失敗・価格やページ数の不一致では購入を有効にしません。設定の変更だけではBOOTHの商品作成・ファイル登録・決済は行われません。

無料アプリの恋愛リーディング最終画面とフッターから案内します。誕生日や相談の内容を商品ページに渡しません。計測用の外部サービス・新たな個人情報収集は追加していません。

ローカルHTTPで `APP_URL=http://127.0.0.1:8765/ryoko-oracle/ node tests/commerce-flow.cjs` を実行し、375px・390px・1440pxで検証しています。PlaywrightとChromiumが必要です。購入先を切り替えるテストは設定レスポンスをモックしてリンク表示を検証するもので、実際の決済・受け取りを検証したものではありません。
