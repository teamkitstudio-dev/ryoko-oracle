# りょうこ・れんの恋愛カード占い

旧ワークブック案は取りやめました。占いの方向性は `../PRODUCT_DIRECTION.md` を参照してください。

- `index.html`：現状・7日間の流れ・開運の一手を占う、改訂版の案内。
- `sample.html`・`sample.pdf`：4ページの無料サンプル。5枚から直感で選び、対応する5つの現状占いの結果へ進めます。
- `assets/love-oracle-v2.png`：りょうこ・れんと新しい商品名を入れた商品画像。本編PDFにも使用。
- `shop.js`・`config.json`：購入先の設定。商品バージョン2.0に限定。

本編は20ページ、固定の15枚と解釈を使う3段階・各5択のカード占いPDFです。5つの恋の状況、12星座の補足を収録。入力フォーム・シャッフル・日替わり生成・AIチャット・個別相談の機能はありません。未来や第三者の気持ち、恋の結果は保証しません。

本編と生成ソースは公開Gitの外で管理します。管理者向け受け取りページには、本編と表紙の暗号文だけを配置します。平文で公開するPDFは無料サンプルだけです。

`saleEnabled: false`、`checkoutUrl: null` のままです。公開済みBOOTH旧商品のPDF・説明・商品画像はこの環境から変更できていません。改訂版の登録内容が確認できるまで購入リンクを有効にしません。旧商品の公開報告を改訂版の登録完了と取り違えないでください。

375px・390px・1440pxのローカルChromiumで、商品案内、5択サンプルの全リンク、PDF取得、画像、FAQ、横スクロール・JavaScript例外なし、旧バージョン設定による購入リンクの無効化を検証。既存の3枚の進行と日替わり運勢も確認しました。
本編20ページ・サンプル4ページの全ページではみ出し検査、PDF内15結果へのリンク、3枚の125通りの経路、12星座、サンプルの5つの異なる移動先、旧ワーク本文の除去、PDFにフォームとJavaScriptがないことを確認しています。本編の選択画面・結果・星座ページを実際のPDF描画で目視確認しました。

iPhone・Android実機、公開URL上の今回の操作、BOOTHでの差し替えと実決済は未検証です。購入リンクの有効化テストはモックのみです。公開処理は対象コミットのGitHub Actionsで確認します。
